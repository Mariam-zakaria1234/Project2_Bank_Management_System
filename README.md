# Bank Management System (C++)

A console-based **Bank Management System** developed in C++ using **Object-Oriented Programming (OOP)** principles. This project allows users to manage bank accounts efficiently with persistent data storage.

---

## 🚀 Features
- **Create Account:** Add a new bank account with unique details.
- **Deposit & Withdraw:** Perform secure transactions and update balances.
- **Display Accounts:** View details of a specific account or list all accounts in the system.
- **File Handling:** Automatically save and load account data to/from text files (`accounts.txt`) to ensure data persistence between sessions.
- **Smart Pointers:** Utilizes `std::shared_ptr` for memory management and safety.

---

## 🛠️ Technologies Used
- **Language:** C++
- **Concepts:** Object-Oriented Programming (Classes, Inheritance, Vectors, Pointers, File I/O)
- **Environment:** Visual Studio

---

## 📂 Project Structure
- `bank.hpp` / `bank.cpp`: Core banking logic and class definitions.
- `Account.hpp`: Account structure and operations.
- `accounts.txt`: Text file used for data storage.
- `main.cpp`: Entry point for the application.
